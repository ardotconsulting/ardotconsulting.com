# ardotconsulting.com

Main website for ARDOT Consulting — AI automation solutions for businesses.

## Overview

This is a single-page marketing website hosted on GitHub Pages. It showcases our consulting services, process, industries served, and provides a contact form.

The site is built with vanilla HTML, CSS, and JavaScript — no build step, no dependencies, no frameworks. It loads fast and works everywhere.

## Structure

```
index.html   — The complete website (self-contained)
README.md    — This file
```

## Development

Just open `index.html` in a browser. Or serve locally:

```bash
python3 -m http.server 8000
# Visit http://localhost:8000
```

## Deployment

The site deploys automatically via GitHub Pages from the `main` branch root. Push to `main` and changes are live within minutes.
